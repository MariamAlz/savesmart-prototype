# SaveSmart

> **Project:** Senior Design Project (team) · BSc Computer Engineering, Khalifa University · 2nd place in energy efficiency, Solar Decathlon Middle East

Mobile application for monitoring appliance energy usage in the Khalifa University smart home.

## What I built

A Xamarin.Forms app prototype (Android, iOS, UWP) with a local device database, on/off switches for appliances, and a recommendations page for when to run them.

Related: [SaveSmart-AI](https://github.com/MariamAlz/SaveSmart-AI) (forecasting models) · [SaveSmart-App](https://github.com/MariamAlz/SaveSmart-App) (team's final system)
